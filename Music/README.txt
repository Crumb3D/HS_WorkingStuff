Hi-fi music

Put .mp3, .ogg or .wav files here, or in %AppData%\7DaysToDie\HSWorkingStuff\Music (made the first time a hi-fi looks for music).
The tracks play in file name order, so start the names with 01, 02, 03 to set the order. Up to 64 tracks.
Each player's PC plays the music, so in multiplayer everyone needs the same files. The server needs none.
