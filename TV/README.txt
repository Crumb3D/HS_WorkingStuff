HS Working Stuff TV channels

Every video file in this folder is a TV channel: .mp4 (H.264 video, AAC sound) works best; .m4v, .webm and .mov also play.
Channels are in file name order, so name them 01 News.mp4, 02 Films.mp4 and so on. The channel name shown in game is the file name.

You can also put videos in:
  %AppData%\7DaysToDie\HSWorkingStuff\TV
That folder is made the first time you look at a TV, and survives mod updates.

New files show up in game within a few seconds. Every player renders the TV on their own PC, so in multiplayer
each player needs the same files to see the same channels. The dedicated server doesn't need any videos.
